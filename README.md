
# にゃんのために。

## サービスURL

https://nyann-no-tameni.onrender.com

## 1. サービス概要（※最後に書いてOK）

ダイエットが続かない人向けに、猫の育成要素を取り入れたダイエットアプリです。
毎日体重を記録することで、"ガリガリにゃんこ"を"まん丸にゃんこ"まで育てましょう!!
猫のために頑張ることで、ダイエットのモチベーションを維持できます。

## 2. このアイデアはどこから生まれたか

### 2-1. きっかけ

卒業制作のアプリをなににしょうか考えてた時に、友達に「ダイエットアプリは？」と言われたのがきっかけ。
ダイエットアプリなんて、そもそも続かない人はアプリを開かないだろうと思ったけど、じゃあどうしたらアプリをひらいてくれて、なおかつダイエットしてくれるだろうと考えから始まりました。

### 2-2. なぜ猫ｘダイエットアプリなのか

私は猫を愛しています。世界でいちばん尊い種族は「猫」と言い切れるほどに笑
そんな猫が例えバーチャルの猫でもガリガリでいたら助けたいよね、ダイエットなんて簡単だよね？強制ダイエットアプリの完成だと思いました。

## 5. 既存サービス・競合調査

### 5-1. 似たサービス

- サービス名：Habitica（ハビティカ）
- URL：https://habitica.com/static/home
- どんなことができるか：体重測定や間食我慢などの目標を自分で登録。達成すると経験値や通貨を獲得し、キャラがレベルアップ。サボるとHPが減るペナルティ機能貯めた通貨でペットの卵や装備を購入・育成

### 5-2. それでも作りたい理由

このアプリは、ダイエットを「自分のために頑張るもの」ではなく、「猫を元気に育てるために続けるもの」へと変えることに意義があると思っています。

「自分が頑張ることで猫が元気になる」という関係を作ることで、ダイエットそのものへのモチベーションを維持することを目指します。

自分のためだけだと人間どこか甘えてさぼってしまうが、猫のため、自分以外のためだと人間頑張れる実体験からこのアプリを作りたいです。

### 5-3. このアプリの価値は

自分以外のために頑張って結果がでたときには何にも得難い達成感が味わえると思います。

## 7. このアプリで実現すること

### MVPで実装した機能

- ユーザー登録・ログイン・ログアウト機能
- 目標体重設定機能
- 体重記録・編集機能
- 猫の成長機能
  - 体重を記録することで元気ポイントを獲得
  - 元気ポイントに応じて猫が成長
  - 猫の成長は「ガリガリにゃんこ」「痩せ気味にゃんこ」「普通にゃんこ」「まん丸にゃんこ」の4段階
  - 成長段階に応じて猫の画像やメッセージが変化
  - 最終段階の「まん丸にゃんこ」になるためには目標体重の達成が必要
- 目標達成後に新しい猫を育てられる機能
- 体重推移グラフ
- リマインダーメール機能
  - 当日の体重記録がないユーザーへリマインダーメールを送信
  - 猫の成長段階に応じたメッセージをランダムで表示

### 本リリースで実装予定の機能

- 猫のバリエーションを増やす
- 猫からの応援メッセージ機能
- SNSシェア機能

## 8. 懸念点とその対策

### 目標達成後の継続利用

目標体重を達成して猫が「まん丸にゃんこ」まで成長すると、そこでアプリを使わなくなってしまう可能性があります。

その対策として、目標体重を達成した後に新しい猫を育て始められる機能を実装しました。

これにより、一度目標を達成した後も新しい目標を設定し、継続して体重記録と猫の育成を行えるようにしています。

### 10-2. 技術選定の比較検討

#### Ruby on Rails / Django

Ruby on RailsとDjango（Python）を比較しました。

どちらでも本アプリに必要な機能は実装可能ですが、Ruby on Railsはカリキュラムで学習しており、CRUDや認証機能の実装経験があったため、限られた開発期間でMVPを完成させやすいと判断して採用しました。

#### PostgreSQL / MySQL

PostgreSQLとMySQLを比較しました。

どちらでも本アプリに必要なデータ管理は可能ですが、ユーザー・ダイエット挑戦・体重記録・猫などの関連するデータをRailsで管理することを想定し、PostgreSQLを採用しました。

#### デプロイ環境

本番環境にはRenderを採用しました。

RailsアプリケーションとPostgreSQLを利用した構成をデプロイし、MVPをインターネット上で公開しています。

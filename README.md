# ダイエットでにゃんこ育成

## キャッチコピー
**「猫のためなら痩せることなんてわけないでしょ？」**

## 概要
ダイエットが続かない人向けに、猫の育成要素を取り入れたダイエットアプリです。
毎日体重を記録することで、"ガリガリにゃんこ"を"まん丸にゃんこ"まで育てましょう!!

## 解決したい課題
- ダイエットが続かない
- モチベーションが維持できない
- 成果が見えにくい

## ターゲットユーザー
**「猫のためなら何でも頑張れる人」**
- ダイエットしたいけど続かない人
- 猫が好きな人
- 楽しく続けられる方法を探している人

## 主な機能
- ユーザー登録・ログイン
- 体重記録機能
- 猫の育成機能（経験値、レベルアップ、見た目の変化）
- グラフ表示

## 使用技術
- Ruby on Rails
- PostgreSQL
- Heroku
